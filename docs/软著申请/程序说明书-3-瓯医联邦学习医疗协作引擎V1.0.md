## 第 1 页：软件概述

### 1.1 开发目的
单一医院病例量有限，AI 模型难以达到可用精度；集中汇总各院数据又违反《个人信息保护法》《数据安全法》。本软件开发目的：
1. 让多家医院在原始数据不出院的前提下联合训练临床风险模型（如再入院风险预测）；
2. 提供联邦统计标准化能力，跨院分布差异不打偏模型；
3. 以差分隐私分级保护上传的模型参数，防止梯度反演泄露个体信息；
4. 输出逐院公平性评估，确保协作对每家参与医院都有增益。

### 1.2 主要功能
多机构联邦学习任务编排（FedAvg）、差分隐私分级保护（DP-FedAvg）、联邦统计标准化、任务结果审计存证上链、逐院公平性评估报告、真实数据集验证（UCI 心脏病 297 例，三机构非IID划分）。

### 1.3 运行环境
- 硬件：4 核 CPU / 8GB 内存（无需 GPU）
- 操作系统：Windows 10+ / Ubuntu 22.04+ / 信创环境
- 支撑软件：Python 3.11+、NumPy、pandas、scikit-learn
- 开发语言：Python 3.13

    前端（Next.js 14）

           ├─ 三院数据全景（样本量/再入院率/缺失率——联邦统计口径）

           ├─ AUC 收敛曲线（逐轮绘制）

      ├─ routers/federation.py            联邦任务 API
      └─ services/federated/
            ├─ engine.py       FedScaler/LogisticModel/fed_average/

## 第 3 页：主要功能与操作流程（一）——发起联邦训练

1. 管理员进入"联邦协作网络"页，查看三家医院数据全景（样本量、再入院率、缺失率——联邦统计口径，无个体记录）；
2. 配置任务参数：联邦轮次（1-50）、本地 Epoch（1-20）、差分隐私档位（关闭/σ=0.01/0.03/0.08）；
3. 点击"发起联邦训练"，系统执行：联邦统计标准化 → 各院本地训练 → 参数上传（差分隐私加噪）→ 服务器加权聚合（FedAvg）→ 循环至收敛；
4. 输出：AUC 收敛曲线、最终 AUC、逐院公平性对比（本院本地模型 vs 联邦模型）；
5. 每轮耗时约 94ms（12 轮全流程），纯 CPU 实时完成。

## 第 4 页：主要功能与操作流程（二）——联邦统计标准化

1. 训练前各院上报标准化所需矩信息：样本量 n、特征和 sum、特征平方和 sum_sq（不含个体记录）；
2. 服务器聚合矩信息计算全局均值与方差，生成各院标准化参数；
3. 各院本地应用标准化，消除跨院量纲与分布差异；
4. 矩信息无法还原个体数据（n 个数聚合成 3 个统计量）；
5. 该机制解决非 IID 场景下"某院分布偏斜打偏全局模型"的经典问题。

## 第 5 页：主要功能与操作流程（三）——差分隐私与公平性

1. 差分隐私（DP-FedAvg）：客户端模型更新先做 L2 范数裁剪（限制单样本影响），再加高斯噪声（σ 分档：0.01/0.03/0.08，档位越高隐私越强、精度损失越大）；
2. 档位在前端可视切换，训练前后 AUC 变化实时呈现"隐私-效用"权衡；
3. 逐院公平性评估：对每家参与医院，分别计算"仅用本院数据训练的本地模型 AUC"与"联邦模型在本院的 AUC"；
4. 输出公平性报告：联邦模型应使每院的 AUC 均不低于本地基线（协作普惠性验证）；
5. 任务结束输出逐院对比表，若某院无增益则标注提示。

## 第 6 页：技术特点（一）

1. **真实数据验证**：UCI 心脏病数据集 297 例真实患者，按机构划分三份非 IID 子集，联邦 AUC 0.9091 追平集中式上界 0.9019（追平/反超）——验证引擎在真实数据上的有效性；
2. **隐私-效用量化**：σ 分档实测 AUC 损失可视，为隐私预算决策提供数据支撑；
3. **存证上链**：每轮训练结果计算 sha256，与前一任务哈希串联，训练过程可审计可复现；
4. **公平性可验证**：逐院 AUC 对比机制确保协作对所有参与方有增益，而非牺牲弱院成全强院。

## 第 7 页：技术特点（二）

5. **轻量实时**：12 轮联邦训练全流程 94ms（纯 CPU），支持现场演示与交互式调参；
6. **非 IID 建模**：合成数据生成器按机构差异化分布（模拟真实跨院差异），联邦统计标准化针对性校正；
7. **纯 Python 实现**：不依赖 TensorFLow/FedML 等重型框架，NumPy + scikit-learn 自研聚合与训练逻辑，便于审计与信创移植；
8. **质量保障**：联邦统计/FedAvg/差分隐私/公平性评估均有单元测试覆盖。

## 第 8 页：使用注意事项

1. 生产部署须升级为跨院网络拓扑（各院独立节点 + mTLS 通信），本 V1.0 为单机模拟编排；
2. 差分隐私正式使用前应完成隐私预算核算（RDP/矩会计，输出精确 ε, δ）；
3. 联邦参与方应签署合作协议，明确数据权属与收益分配（与流通平台 70/20/10 分成衔接）；
4. 模型输出用于临床决策支持，不替代医生诊断。
