# 瓯医数链 生产化改造计划（含验收标准）

> 目标：从比赛原型升级为可支撑真实医院接入、满足园区入驻考核的生产级产品。
> 总量：约 6-9 人月技术改造 + 外部采购项（等保测评约 10-20 万）。
> 原则：每一项都有可验证的验收标准；先做"阻塞医院接入"的项。
