# 瓯医数链 数据分类分级管理办法

> 版本：v1.0（2026-10-11）｜适用范围：瓯医数链 OuMedTrust 平台全部数据资产（数据库表、文件存储、日志、导出物）
> 制定依据：GB/T 39725-2020《信息安全技术 健康医疗数据安全指南》、GB/T 43697-2024《数据安全技术 数据分类分级规则》、
> 《数据安全法》《个人信息保护法》；落地流程参考上海 DB31/T 1545-2025 四步法。
> 配套文件：`docs/PIA-个人信息保护影响评估报告.md`（处理目的与法律依据）、`docs/生产化改造计划.md`（P0-1.3 验收）。

## 一、分类分级框架（双框架对照）

### 1.1 分类：GB/T 39725-2020 六大类

| 类别 | 定义 | 本平台典型数据 |
|---|---|---|
| 个人属性 | 身份标识与人口学属性 | 姓名、邮箱、年龄、性别、城市、IP |
| 健康状况 | 生理/心理状态、诊断、健康自述 | 诊断、用药史、脑电评估、影像报告、泛癌风险、健康档案原文 |
| 医疗应用 | 医疗服务消费与就医记录 | 就诊记录、检查类型、费用、支付订单 |
| 卫生资源 | 医疗与医保资源 | 医院/科室、参保类型、缴费基数 |
| 公共卫生 | 聚合统计与公共卫生服务 | 联邦聚合 AUC、政策文本、数据产品目录 |
| 其他 | 系统与治理元数据 | 哈希、存证令牌、审计事件、会话元数据 |

### 1.2 分级：GB/T 39725-2020 五级 × GB/T 43697-2024 对照

| 级别 | 名称 | 判定要点 | GB/T 43697 对照 | 核心管控要求 |
|---|---|---|---|---|
| 5 | 特殊敏感数据 | 基因组、生物样本、特殊疾病专项 | 核心（如涉） | 本平台暂不涉及；涉及时单独评审 |
| 4 | 敏感健康医疗数据 | 一经泄露/滥用导致人格尊严、身心健康受损（诊断/用药/生理心理/健康预测） | 批量汇集 = **重要数据**；单条 = 敏感个人信息 | **存储加密（AES-256-GCM）** + 单独同意 + 禁出域交易 + 导出脱敏 + 访问留痕 |
| 3 | 一般个人信息 | 身份标识（姓名/邮箱/IP）、财产类（缴费/费用/交易号） | 一般（个人信息） | 访问控制 + 传输加密 + 展示脱敏 |
| 2 | 内部一般属性 | 年龄/性别/城市/就医类型等非标识属性 | 一般 | 访问控制 + 会话校验 |
| 1 | 公开/非个人 | 政策文本、哈希、聚合结果、系统元数据 | 一般（非敏感） | 常规保护（备份/审计兜底） |

**GB/T 43697-2024 结论**：本平台数据总体为"一般"级；4 级字段批量汇集形成的健康医疗数据集为"**重要数据**"，
对外提供前必须去标识化 + 隐私增强（差分隐私/联邦聚合，见 P1）；无"核心数据"（不涉国家安全）。

## 二、分级判定规则（供新字段定级）

1. **可识别性**：能单独或组合识别自然人 → ≥3 级；
2. **健康相关性**：反映身心健康状况（含推断性评估如风险等级/心理状态）→ 4 级；
3. **财产敏感性**：缴费、费用、支付交易号 → 3 级；
4. **不可逆衍生**：单向哈希（密码哈希/存证哈希）按用途定级，凭据类 3 级、存证类 1 级；
5. **聚合降级**：K-匿名聚合（联邦 AUC、统计产物）降为 2/1 级，前提是聚合粒度 ≥ 机构级且不含个体轨迹；
6. **就高原则**：多规则命中取最高级；自由文本字段（对话/备注/文件名）按**可能含有的最高敏感内容**就高定级。

## 三、落地流程（DB31/T 1545-2025 四步法）

```
① 盘点 → ② 分类 → ③ 定级 → ④ 打标签·动态更新
```

- **① 盘点**：以 SQLAlchemy 元数据为准，穷举全部表/列（当前 20 张表，与 PIA 报告一致口径）；
- **② 分类**：按六大类归入类别；
- **③ 定级**：按第二节规则逐字段定级；
- **④ 打标签**：字段级标签固化在 `backend/app/data_classification.py` 台账（机器可读唯一事实源），
  并通过测试 `tests/test_data_classification.py` 强制校验——**新增表/列而未登记分级标签，CI 直接失败**，
  实现"动态更新"（结构变更必须同步标签）。

## 五、脱敏与流通策略（按级别）

| 级别 | 展示脱敏 | 导出/接口 | 对外流通（数据要素市场） | 外部 LLM 出域 |
|---|---|---|---|---|
| 4 | 按需脱敏；仅本人会话可见 | 作用域校验（X-User-Token）+ 越权审计 | **禁止**（仅去标识化统计产物可上架） | 最小化原则：仅发送必要片段，禁止携带标识；PIA 4.3 出域面管控 |
| 3 | 邮箱 `a***@x.cn`、IP 段掩码 | 作用域校验 | 禁止 | 最小化 + 禁止携带 |
| 2 | 可展示 | 作用域校验 | 仅聚合产物形态 | 允许（不携带标识） |
| 1 | 可展示 | 登录态/公开 | 允许（去标识化后上架） | 允许 |

去标识化流通路径（平台既有实现）：原始 4 级数据不出院 → 联邦学习仅梯度出域（DP-FedAvg 加噪）→
聚合 AUC 存证上链 → 数据产品目录仅上架统计产物与模型 API（privacy_tech 标签），满足
"可用不可见、可控可计量"。

## 七、动态更新机制

- **结构变更**：模型新增表/列 → 台账同步登记（CI 强制）→ PIA 报告增量修订（如涉新处理目的）；
- **年度复审**：每年至少一次全量复核（法规更新/新业务线触发时即时复审）；
- **版本记录**：本文件修订经技术负责人 + 法务双签，历史版本归档。
